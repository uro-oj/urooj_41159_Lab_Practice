# 🧪 List of Experiments

## 🔹 Experiment 01 — Python Basics
### *Syntax • Data Types • Operators*

The first experiment introduces the building blocks of Python programming.

### 🎯 Objectives

- Understand **Python tokens and keywords**
- Demonstrate **variable declaration and dynamic typing**
- Explore basic data types:
  - `int`
  - `float`
  - `str`
  - `bool`
- Perform:
  - Arithmetic operations
  - Relational operations
  - Logical operations
  - Assignment operations
- Understand **operator precedence**
- Practice **type casting**
- Use `input()` for interactive programs
- Perform basic computations using user input

### 🧠 Concepts Covered

`Variables` · `Data Types` · `Operators` · `Expressions` · `Type Casting` · `Input/Output`

---

## 🔹 Experiment 02 — Control Flow & Collections
### *Decisions • Loops • Data Structures*

This experiment focuses on controlling program execution and organizing data efficiently.

### 🎯 Objectives

#### 🔀 Control Flow

Implement programs using:

- `if`
- `if-else`
- Nested `if`
- `for` loops
- `while` loops

#### 📦 Collections

Work with Python's built-in data structures:

| Collection | Concepts |
|---|---|
| 📝 **List** | `append()` · `insert()` · `remove()` · slicing |
| 🔒 **Tuple** | Indexing · Immutability |
| 🔗 **Set** | Union · Intersection · Difference |
| 📖 **Dictionary** | Add · Update · Delete |

#### 🌍 Real-World Application

Build a simple **Student Record System** using Python collections.

### 🧠 Concepts Covered

`Conditions` · `Loops` · `Lists` · `Tuples` · `Sets` · `Dictionaries` · `Data Organization`

---

## 🔹 Experiment 03 — Functions & Recursion
### *Modularity • Reusability • Problem Solving*

This experiment explores how complex programs can be broken into smaller, reusable components.

### 🎯 Objectives

- Define and call **user-defined functions**
- Demonstrate:
  - Default arguments
  - Keyword arguments
  - Variable-length arguments
- Use **lambda functions**
- Work with:
  - `map()`
  - `filter()`
- Implement recursive programs:
  - Factorial
  - Fibonacci series
- Build a small application using **modular functions**

### 🧠 Concepts Covered

`Functions` · `Arguments` · `Lambda` · `map()` · `filter()` · `Recursion` · `Modularity`

> 💡 **Core idea:** Write code once, reuse it everywhere.

---

## 🔹 Experiment 04 — Modules & Regular Expressions
### *Code Organization • Automation • Pattern Matching*

This experiment takes Python beyond individual programs and introduces reusable code and text-processing techniques.

### 🎯 Objectives

### 📦 Standard Modules

Explore and use:

- `math`
- `sys`
- `time`
- `os`

### 🧩 User-Defined Modules

- Create a custom Python module
- Import and use the module in another program

### 📁 Packages

- Create a Python package
- Organize multiple modules inside a package
- Import modules from the package

### 🔍 Regular Expressions

Implement programs to:

- Validate email addresses
- Extract mobile numbers from text
- Demonstrate regular expression **metacharacters**

### 🧠 Concepts Covered

`Modules` · `Packages` · `Imports` · `os` · `math` · `sys` · `time` · `Regex` · `Pattern Matching`

---

## 🔹 Experiment 05 — File Handling & Exception Handling
### *Persistence • Error Handling • Robust Programs*

The final experiment focuses on handling external files, directories, and unexpected errors safely.

### 🎯 Objectives

### 📄 File Handling

Demonstrate file access modes:

```text
r → Read
w → Write
a → Append
```

Implement programs to:

- Write data to a file
- Read data from a file
- Use the `with` statement
- Work with directories using the `os` module

### ⚠️ Exception Handling

Explore:

```python
try
except
else
finally
```

Also implement:

- Multiple exception handling
- `raise`
- `assert`
- Custom exceptions

### 🧠 Concepts Covered

`Files` · `Directories` · `with` · `try-except` · `raise` · `assert` · `Custom Exceptions`
